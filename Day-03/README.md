# Day 03 - Tokens, Tokenization & Prompt Fundamentals

## 📖 Overview

On Day 03 of my AI Engineer Journey, I explored how Large Language Models (LLMs) process human language. I learned about tokens, tokenization, context windows, prompts, and how these concepts influence the quality and accuracy of AI-generated responses.

Understanding these fundamentals is essential before learning Prompt Engineering because every interaction with an LLM starts with tokens and prompts.

# 💡 Key Takeaways

- LLMs understand text through tokens, not complete words.
- Tokenization converts text into smaller units for processing.
- Context Window determines how much information the model can remember.
- Better prompts produce better AI responses.
- Understanding tokens is essential for Prompt Engineering.
