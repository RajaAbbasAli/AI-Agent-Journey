# Day 14 - Exception Handling in Python

## Overview

Today I learned one of the most important concepts in Python: **Exception Handling**.

While writing programs, errors can happen because of invalid input, missing files, or incorrect operations. Instead of letting the program crash, Python allows us to handle these errors using Exception Handling.

I also learned how to validate user input and create my own exceptions using the `raise` keyword.
