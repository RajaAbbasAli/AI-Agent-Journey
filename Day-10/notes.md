## Key Concepts

Function:
A reusable block of code that performs a specific task.

Built-in Function:
Functions already provided by Python.

Examples:
- print()
- input()
- len()
- type()

User-defined Function:
A function created by the programmer.

Syntax:

def function_name():
    # code

Function Call:

function_name()

Parameter:
A variable inside the function definition.

Argument:
The actual value passed to the function.
