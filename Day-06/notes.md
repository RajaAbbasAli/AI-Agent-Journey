Python is a high-level, interpreted, and general-purpose programming language created by **Guido van Rossum** and released in **1991**.

# Python Syntax

Python uses indentation instead of braces.

Correct Example:

```python
if True:
    print("Welcome")
```

Incorrect Example:

```python
if True:
print("Welcome")
```

# Variables

Variables are used to store data.

Example:

```python
name = "Abbas"
age = 20
```

---

# Variable Naming Rules

A variable:

- Must begin with a letter or underscore
- Cannot begin with a number
- Cannot contain spaces
- Is case-sensitive

Valid:

```python
name
student_name
age1
_marks
```

Invalid:

```python
1name
student name
class
```

---

# Updating Variables

Variables can be changed later.

# The input() Function

The `input()` function accepts user input.

Example:

```python

print(name)
```

# Simple Input Program

# User Profile Program

```python

age = input("Enter Age: ")

print("----- Profile -----")
print("Name :", name)
print("Age  :", age)
print("City :", city)
```
